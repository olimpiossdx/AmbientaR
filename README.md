# AmbientaR (EcoGestão MG)

Aplicação **Next.js** (PWA) de gestão ambiental para consultorias, com **Firebase** (Auth, Firestore, Storage).

## Arranque rápido

```bash
npm install
npm run dev
```

Servidor de desenvolvimento: **http://localhost:9002** (ver `AGENTS.md` para mais comandos).

## Onde está o código e como alinhar com o GitHub

- **Cópia local recomendada no Windows:** `E:\AmbientaR` — ver [`docs/REPOSITORIO-LOCAL-E-GITHUB.md`](docs/REPOSITORIO-LOCAL-E-GITHUB.md) (fluxo `git pull` / `git push`, `safe.directory`, regras Firestore).
- Instruções para agentes e desenvolvimento: [`AGENTS.md`](AGENTS.md).
- Firebase, deploy e regras: [`.cursor/rules/ambientar-firebase-e-deploy.mdc`](.cursor/rules/ambientar-firebase-e-deploy.mdc) e [`docs/firebase-deploy-rules.md`](docs/firebase-deploy-rules.md).
