# Guia do Usuário - AmbientaR

## Introdução
Bem-vindo ao AmbientaR, a plataforma completa para consultoria ambiental que integra gestão empresarial com funcionalidades especializadas para estudos ambientais.

## Primeiros Passos

### 1. Acesso ao Sistema
- **URL**: http://localhost:8000 (desenvolvimento)
- **Usuário padrão**: admin
- **Senha padrão**: admin123

### 2. Configuração Inicial
1. Altere a senha do usuário admin
2. Configure informações da empresa
3. Defina parâmetros do sistema
4. Importe dados iniciais (opcional)

## Módulos Principais

### Módulo de Projetos

#### Criando um Novo Projeto
1. Acesse **Projetos** → **Novo Projeto**
2. Preencha as informações básicas:
   - Nome do projeto
   - Cliente
   - Categoria ambiental
   - Data de início e término
   - Orçamento
   - Equipe responsável

#### Gerenciando Projetos
- **Dashboard**: Visão geral de todos os projetos
- **Kanban**: Visualização por status
- **Calendário**: Cronograma de projetos
- **Relatórios**: Análises e métricas

### Módulo de Estudos

#### Tipos de Estudo Disponíveis
- **EIA (Estudo de Impacto Ambiental)**
- **RIMA (Relatório de Impacto Ambiental)**
- **EAS (Estudo Ambiental Simplificado)**
- **PCA (Plano de Controle Ambiental)**
- **PGRS (Plano de Gerenciamento de Resíduos Sólidos)**

#### Criando um Estudo
1. Selecione o projeto relacionado
2. Escolha o tipo de estudo
3. Selecione os termos de referência
4. Defina a metodologia
5. Configure cronograma e equipe

### Módulo de Relatórios

#### Gerando Relatórios
1. Acesse o estudo desejado
2. Clique em **Gerar Relatório**
3. Escolha o template
4. Revise os dados
5. Gere o relatório final

#### Templates Disponíveis
- **EIA Padrão**: Template CONAMA
- **RIMA Executivo**: Resumo executivo
- **Relatório Técnico**: Documentação completa
- **Apresentação**: Slides para apresentações

#### Formatos de Saída
- **PDF**: Para impressão e arquivamento
- **Word**: Para edição posterior
- **HTML**: Para visualização web
- **Excel**: Para análises e planilhas

## Solução de Problemas

### Problemas Comuns

#### Login
- **Esqueci a senha**: Use a opção de recuperação
- **Conta bloqueada**: Entre em contato com o administrador
- **Erro de conexão**: Verifique a conectividade

#### Relatórios
- **Erro na geração**: Verifique os dados obrigatórios
- **Formato incorreto**: Confirme o template selecionado
- **Dados faltando**: Complete todas as informações necessárias

#### Sistema
- **Lentidão**: Verifique a conexão com o banco
- **Erro 500**: Consulte os logs do sistema
- **Timeout**: Verifique o tamanho dos dados
